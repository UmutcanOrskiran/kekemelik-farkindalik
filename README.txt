22 EKİM – DÜNYA KEKEMELİK FARKINDALIK GÜNÜ WEB SİTESİ

Açmak için:
1. Bu klasördeki index.html dosyasına çift tıklayın.
2. Site tarayıcıda açılır. Menü, mobil görünüm ve paylaşım butonu dahildir.

YAYINLAMAK (ör. Vercel):
1. Klasörde index.html, style.css, script.js ve assets/logo.png dosyaları bulunmalı.
2. Klasörü GitHub deposuna yükleyin veya Vercel'de bu klasörü proje olarak içe aktarın.
3. Framework Preset: Other; Build Command ve Output Directory gerekmez (statik site).
4. Deploy / Publish seçeneğine basın.

DÜZENLEME:
- Metinler: index.html
- Renkler ve tasarım: style.css dosyasının en üstündeki :root renkleri
- Logo: assets/logo.png (yeni oluşturulan yazısız logo)

Not: Google Fonts bağlantısı için internet gerekir; bağlantı yoksa sistem yazı tipleri kullanılır.
